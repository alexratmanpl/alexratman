Social cards (1200x630 PNG), one per page. Referenced by each page's og:image / twitter:image tags:

  home.png                       /
  learn.png                      /learn/
  from-thought-to-answer.png     /learn/from-thought-to-answer/
  self-improving-skills.png      /learn/self-improving-skills/
  price-of-a-conversation.png    /learn/price-of-a-conversation/

The file name matches the page's folder, so a new piece needs a card of the same name.
Binary files cannot be committed through the connector, so they are uploaded here via the GitHub web UI.

These files are served with Cache-Control: public, max-age=86400 and Cross-Origin-Resource-Policy:
cross-origin (see pages/_headers) — the site-wide same-origin policy would otherwise stop the social
platforms fetching them. After adding or replacing a card, ask each platform to re-read the page, or
it keeps showing what it cached before.
